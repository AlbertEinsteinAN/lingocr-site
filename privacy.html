Lingocr privacy policy

Last updated: 28 October 2026

Lingocr is a personal app that runs on the user's own computer and Android phone. There is no Lingocr server: no data is sent to the app's author or to anyone else.

Google Drive

With the user's permission, Lingocr uses Google Drive with the drive.file scope, which gives it access only to the files and folders it creates itself. It uses them to:

  • back up the user's study data (word statuses, flashcards and the log of text read) to a lingocr folder in the user's own Drive;
  • let the user's phone and computer exchange their study changes and books through that folder.

Lingocr does not read, change or share any other file in the user's Drive, and it does not share Google user data with anyone. Lingocr's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can remove Lingocr's access at any time in their Google Account (myaccount.google.com/permissions) and delete the lingocr folder from their Drive.
